# Разбор технических ошибок недели — Выполнила Айшан

В данном отчете разобраны 3 реальные ошибки, возникшие при разработке и тестировании функционала Telegram-бота и модулей базы данных.

---

### Ошибка 1: Ошибка приведения типов (Неверный разбор call.data)
* **В чем была ошибка:** В обработчике инлайн-кнопок    `handle_habit_click` строка кода выглядела так:
  `habit_id = int(call.data.split('_'))`
  Метод `split()` возвращает список строк, а функция `int()` не может преобразовать список в число. Это приводило к падению обработчика.
* **Как она была найдена:** Ошибка была локализована через просмотр логов терминала VS Code (traceback ошибки `TypeError`).
* **Исправленный код:**
  ```python
  habit_id = int(call.data.split('_')[1])
  ```
* **Тестирование решения:**
  * Входной набор 1: `call.data = "done_15"`. Ожидаемый результат: `habit_id = 15`. Результат теста: Успешно.
  * Входной набор 2: `call.data = "done_99"`. Ожидаемый результат: `habit_id = 99`. Результат теста: Успешно.

### Ошибка 2: Ошибка отступов и логики (IndentationError в функции calculate_streak)
* **В чем была ошибка:** В файле `database.py` внутри функции `calculate_streak` при переносе строк SQL-запроса и условий `if/elif` съехали невидимые пробелы. Код внутри функции оказался разломан, из-за чего Python выдавал ошибку отступов, а сам расчет серии дней не выполнялся до конца.
* **Как она была найдена:** Ошибка была обнаружена при запуске модульных юнит-тестов командой `python -m unittest test_streak.py`.
* **Исправленный код функции и тестов:**
  ```python
  def calculate_streak(logs_dates_list, target_date_str):
      if not logs_dates_list:
          return 0
      sorted_dates = sorted([datetime.strptime(d, "%Y-%m-%d") for d in logs_dates_list], reverse=True)
      target_date = datetime.strptime(target_date_str, "%Y-%m-%d")
      streak = 0
      current_check = target_date
      if current_check in sorted_dates:
          pass
      elif (current_check - timedelta(days=1)) in     sorted_dates:
          current_check = current_check - timedelta(days=1)
      else:
          return 0
      while current_check in sorted_dates:
          streak += 1
          current_check -= timedelta(days=1)
      return streak
  ```
* **Тестирование решения:**
  * Входной набор 1: Пустой список логов `[]`, дата `"2026-10-23"`. Ожидаемый результат: `0`. Результат теста: Успешно.
  * Входной набор 2: Логи `["2026-10-21", "2026-10-22", "2026-10-23"]`, дата `"2026-10-23"`. Ожидаемый результат: `3`. Результат теста: Успешно (тесты пройдены).

### Ошибка 3: Синтаксическая ошибка компиляции (SyntaxError: оторванный оператор)
* **В чем была ошибка:** В конце файла `bot.py` после строки `bot.infinity_polling()` из-за некорректного копирования остался одинокий изолированный оператор `return` вне какой-либо функции, что ломало запуск компилятора.
* **Как она была найдена:** По сообщению об аварийной остановке `SyntaxError` в консоли терминала.
* **Исправленный код:** Лишняя строка с оператором `return` была полностью удалена.
  ```python
  if __name__ == "__main__":
      bot.infinity_polling()
```
* **Тестирование решения:**
  * Входной набор 1: Запуск бота с лишним `return`. Результат: Аварийное падение.
  * Входной набор 2: Запуск после очистки. Результат: Успешный запуск бота и создание резервной копии БД.
