# Разбор технических ошибок недели — Выполнила Айшан

В данном отчете разобраны 3 реальные ошибки, возникшие при разработке и тестировании функционала Telegram-бота и модулей валидации.

---

### Ошибка 1: Ошибка приведения типов (Неверный разбор call data)
* **В чем была ошибка:** В обработчике инлайн-кнопок          `handle_habit_click` строка кода выглядела так:
  `habit_id = int(call.data.split('_'))`
  Метод `split()` возвращает список строк, а функция `int()` не умеет превращать список в число. Это приводило к падению обработчика, и отметка о выполнении привычки не доходила до базы данных.
* **Как она была найдена:** Ошибка была локализована через просмотр логов терминала VS Code, где отображался traceback ошибки `TypeError`.
* **Исправленный код:**
  ```python
  habit_id = int(call.data.split('_')[1])
  ```
* **Тестирование решения:**
  * Входной набор 1: `call.data = "done_15"`. Ожидаемый результат: `habit_id = 15`. Результат теста: Успешно.
  * Входной набор 2: `call.data = "done_99"`. Ожидаемый результат: `habit_id = 99`. Результат теста: Успешно.

### Ошибка 2: Ошибка отступов (IndentationError в модуле базы данных)
* **В чем была ошибка:** В файле `database.py` при переносе параметров SQL-запроса `cursor.execute` внутри функции `calculate_streak` случайно сбились невидимые пробелы (отступы). Новая строка кода оказалась оторвана от основного блока, из-за чего интерпретатор Python выдавал ошибку:
`IndentationError: expected an indented block`.
* **Как она была найдена:** Ошибка была обнаружена автоматически при попытке запустить модульные юнит-тесты через команду `python -m unittest test_streak.py`.
* **Исправленный код:**
  ```python
  def calculate_streak(logs_dates_list, target_date_str):
      if not logs_dates_list:
          return 0
      # Все строки функции выровнены строго по 4 пробела
  ```
* **Тестирование решения:**
  * Входной набор 1: Запуск тестов при сломанных отступах. Ожидалось: Сбой компиляции. Результат: Успешно подтверждено.
  * Входной набор 2: Запуск тестов после выравнивания. Ожидалось: `Ran 5 tests... OK`. Результат: Успешно, тесты пройдены.

### Ошибка 3: Синтаксическая ошибка компиляции (SyntaxError: оторванный оператор)
* **В чем была ошибка:** В самом конце файла `bot.py` после строки `bot.infinity_polling()` из-за некорректного копирования из буфера обмена остался одинокий изолированный оператор `return`. Так как он находился вне какой-либо функции (`def`), Python блокировал запуск программы с ошибкой `SyntaxError: expected 'except' or 'finally' block`.
* **Как она была найдена:** Путем визуального анализа кода на строке 240 и по сообщению об аварийной остановке в консоли.
* **Исправленный код:** Лишняя строка с оператором `return` была полностью удалена, а функция запуска прижата к левому краю:
  ```python
  if __name__ == "__main__":
      bot.infinity_polling()
  ```
* **Тестирование решения:**
  * Входной набор 1: Запуск бота с лишним `return`. Результат: Аварийное падение.
  * Входной набор 2: Запуск после очистки. Результат: Сообщение `INFO - Бот успешно инициализирован в системе.`
